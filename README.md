# WaterFinder

A native iOS app that finds public drinking water for cyclists, through-hikers, and other long-distance travelers. Data comes from OpenStreetMap, plus community submissions that moderators approve.

- `app/` — SwiftUI + MapKit iOS app (phase 1: read-only OSM map)
- `tools/explorer/` — browser map to explore and validate OSM water data
- `CLAUDE.md` — standing context for Claude Code
- `HANDOFF.md` — current state, decisions, and next tasks
